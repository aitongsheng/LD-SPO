# Public sample data

`ldspo_sample.csv` contains 360 deterministic synthetic rows for two fictional symbols covering 2023-01-02 through 2023-09-08.

It includes the 21 numerical features, four aligned-news fields, the 11 paper-named teacher probabilities, and a value target. It is provided only to exercise the software pipeline and must not be used to report financial performance.

The complete research datasets are excluded because their market records and news text are governed by third-party licenses and copyright restrictions. See `docs/DATA.md` for details.
